# 👑 the-daddy-lang

Welcome to **the-daddy-lang** – a comprehensive and hands-on journey into the C programming language, often hailed as *"the father of modern programming languages."* This repository serves as a structured learning archive, covering C from its basic syntax to advanced system-level concepts.

Whether you're a student, self-learner, or systems programming enthusiast, this repo aims to provide clarity, structure, and practice material to master the language.

---

## 📚 What’s Inside

This repo is divided into **4 main modules**, each representing a major phase of learning:

### 1. 🧱 Introduction to C
Covers foundational topics such as:
- Syntax, data types, control structures
- Functions and scope
- Pointers and memory management

### 2. 🏗️ Data Structures
Learn to build fundamental data structures from scratch in C:
- Linked lists, stacks, queues
- Trees, heaps, and hash tables

### 3. ⚙️ Algorithms
Implement key algorithms:
- Sorting and searching techniques
- Graph algorithms (DFS, BFS, Dijkstra)
- Dynamic programming and greedy algorithms

### 4. 🚀 Advanced Concepts
Go beyond the basics with:
- Multithreading and synchronization
- Inter-process communication
- Socket programming
- Inline assembly
